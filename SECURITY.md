# Segurança e relatos responsáveis

O repositório contém uma fundação documental/contratual, não um prontuário clínico implantado. Não há versão de aplicação liberada para pacientes reais. Não testar ataques em sistemas de saúde ou produção alheia com base neste material.

Não publicar dados de paciente, prontuário, exames, imagens identificáveis, credenciais, certificados ou dumps em issue/PR. Para falha documental ou bug reproduzível sem risco de exposição, use fixture fictícia e descreva versão, comportamento e limites.

Para vulnerabilidade com detalhes sensíveis, prefira **Security → Advisories → Report a vulnerability**, se o mantenedor tiver habilitado relatos privados. Se essa opção não estiver disponível, abra somente um pedido genérico de canal privado, sem payload explorável, dados sensíveis ou credenciais. Nenhum endereço de e-mail ou SLA de resposta foi definido neste projeto.

Pacientes reais exigem engenharia/privacidade/profissão/operação homologadas, plano de incidente e responsável da implantação. Uma correção de teste ou a licença MIT não equivale a aprovação para uso assistencial.
